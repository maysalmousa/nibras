# نبراس — Nibras

منصة رصد عيوب أسطح الطرق في المملكة العربية السعودية.

## التشغيل
- افتحي `index.html` في المتصفح مباشرة، أو
- في VS Code ثبّتي إضافة **Live Server** ثم اضغطي يمين على `index.html` ← **Open with Live Server**.

## الملفات
| الملف | الوصف |
|---|---|
| `index.html` | هيكل الصفحة (الأقسام، الهيدر، القائمة الجانبية) |
| `css/style.css` | الألوان والوضع الداكن وتنسيق الخريطة |
| `js/app.js` | النصوص (عربي/إنجليزي)، بيانات العيوب، الجداول، الخريطة، النوافذ |
| `js/saudi-map.js` | حدود المملكة ودول الجوار للخريطة |
| `assets/logo.svg` | شعار نبراس (الطريق) |
| `assets/hero.webp` | صورة الطريق في الواجهة |
| `vendor/` | مكتبة Leaflet للخريطة |

## تعديلات شائعة
- **النصوص:** في `js/app.js` داخل `AR` (عربي) و `EN` (إنجليزي).
- **الشعار:** `LOGO_SVG` في أول `js/app.js`.
- **الجهات:** المصفوفة `entities` في `js/app.js`.
- **صورة الواجهة:** استبدلي `assets/hero.webp` بصورة بنفس الاسم.

> التنسيق يعتمد على Tailwind (يتحمّل من الإنترنت)، فيحتاج اتصال نت عند الفتح.

## الربط مع جهاز نبراس (مباشر)
- الموقع يقرأ من Firebase كل 5 ثواني:
  `https://nibs-eb9d5-default-rtdb.europe-west1.firebasedatabase.app/defects.json`
- أي عيب يرسله الجهاز يطلع **فوق في الجدول** مع علامة "مباشر"، وعلى **الخريطة بعلامة أكبر وإطار غامق**، وتطلع رسالة "رصد جديد" والخريطة تروح لمكانه.
- المدينة تتحدد تلقائياً (أقرب مدينة للإحداثيات).
- لتغيير قاعدة البيانات: عدّلي `FIREBASE_URL` في `js/app.js`.
- البيانات التجريبية (150 عيب) باقية عشان الموقع ما يطلع فاضي. لإخفائها: في `js/app.js` غيّري `const DEMO=generate(150);` إلى `const DEMO=[];`
